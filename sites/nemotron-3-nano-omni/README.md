# nemotron-3-nano-omni

`App.tsx` in this folder is the **unedited output** of `nvidia/nemotron-3-nano-omni` for the Petal & Stem task.

- Live page: https://humbertovirtudes.github.io/astryx-model-bench/nemotron-3-nano-omni/
- Metrics: [`../../results/nemotron-3-nano-omni/result.json`](../../results/nemotron-3-nano-omni/result.json)

To run locally, drop `App.tsx` into an Astryx Vite app (`npm create vite`, add `@astryxdesign/core@0.3.0` + `@astryxdesign/theme-neutral`, import the CSS in `main.tsx`).
