# gemma-4-e4b

`App.tsx` in this folder is the **unedited output** of `google/gemma-4-e4b` for the Petal & Stem task.

- Live page: https://humbertovirtudes.github.io/astryx-model-bench/gemma-4-e4b/
- Metrics: [`../../results/gemma-4-e4b/result.json`](../../results/gemma-4-e4b/result.json)

To run locally, drop `App.tsx` into an Astryx Vite app (`npm create vite`, add `@astryxdesign/core@0.3.0` + `@astryxdesign/theme-neutral`, import the CSS in `main.tsx`).
